Sign in to sync across computers

Your tracker, technicals and Excel progress save to a private Gist in your own GitHub account. Sign in once on each computer with the same token and everything stays in sync.

  1. Open this GitHub page (it pre-fills a token that can only touch Gists).
  2. Set Expiration to "No expiration" or 1 year, scroll down, click Generate token.
  3. Copy the token (starts with ghp_) and paste it below. Save it in your password manager to use on your other computer.

What's saved

  • Application status and dates, and your notes on each application.
  • Which technicals you got right or missed.
  • Excel drill answers and quiz scores.

Nothing about people you contact is stored. The networking links and messages are generated fresh each time.

Without signing in, progress still saves in this browser only.
